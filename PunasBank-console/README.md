# 🏦 SecureBank Console Application

A console-based banking application developed in Python as part of the Python Backend Developer roadmap.

## 📌 Features

- Create a Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Close Account
- Custom Exception Handling
- Dictionary-Based Storage
- Dataclass-Based Account Model
- Interactive Command Line Interface (CLI)

## 🛠 Technologies Used

- Python 3
- Dataclasses
- Object-Oriented Programming (OOP)
- Custom Exceptions
- Git & GitHub

## 🚀 How to Run

Clone the repository:

```bash
git clone https://github.com/<YOUR_USERNAME>/securebank-console.git
```

Go to the project:

```bash
cd securebank-console
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it:

### Windows

```bash
venv\Scripts\activate
```

Run the application:

```bash
cd src
python cli.py
```
